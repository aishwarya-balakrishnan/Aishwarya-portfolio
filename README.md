# Aishwarya – Portfolio

One self-contained file: `index.html` (your photo is embedded, so it shows even when the file is opened on its own).

## Update the content
Open `index.html`, find the block "EDIT YOUR CONTENT HERE" and edit the lists
(EDU, SKILLS, PROJECTS, HACKS, CERTS, ACH). To add a hackathon, add a line to HACKS.

## Publish (GitHub Pages)
1. Open https://github.com/aishwarya-balakrishnan/Aishwarya-portfolio
2. Add file > Upload files. Drag in `index.html` (it replaces the old one; GitHub keeps the old version in History).
3. Commit changes to the main branch.
4. Settings > Pages should already be "Deploy from a branch" > main > / (root). Nothing to change.
5. Wait 1-2 minutes, then hard-refresh https://aishwarya-balakrishnan.github.io/Aishwarya-portfolio/
